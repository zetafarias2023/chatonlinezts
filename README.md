# 166 STUDIO
Marketplace de beats multi-productor en Next.js + Supabase + PayPal, con PWA y shell Android mediante Capacitor.

Consultá `SETUP.md` para configurar Supabase, crear el primer administrador, publicar en Vercel y generar el APK/AAB.

**Estado:** versión de desarrollo avanzada. Configuración de credenciales y pruebas de seguridad/pagos obligatorias antes de producción.
